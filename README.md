# Zenith Framework

A modular, server-authoritative FiveM roleplay framework built from scratch on Overextended's `ox_mysql` and `ox_lib`.

## Platform & Target Build
* **Runtime:** FiveM (Lua 5.4 runtime)
* **GTA V Target:** Expanded & Enhanced (build 3258 enforced)
* **UI:** GrandRP-inspired custom React NUI (React 18, Vite, TS, Tailwind)
